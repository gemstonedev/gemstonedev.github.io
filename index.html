NSF Programmable Cloud Laboratory Test Bed

Building America’s AI infrastructure for self-driving laboratories

Scientists should be able to describe an experiment the way they normally would, in prose, and have it run reliably in an automated laboratory. GEMSTONE develops the representation and the AI agents that make that possible, at a programmable cloud laboratory node operated by Emerald Cloud Lab in Austin, Texas.

From prose to execution

A major bottleneck in automated experimentation is method transfer: writing a specification detailed enough to reliably guide a self-driving laboratory. Researchers are not used to writing out the low-level, common-sense details that a machine requires. GEMSTONE places an abstract, node-independent layer between natural language and the platform-specific languages that drive instruments.

Input

Prose protocol

A USP monograph, a journal methods section, or a researcher’s own description.

ORE

Disambiguation

An AI agent flags vague instructions — “mix thoroughly,” “adjust pH as needed” — and resolves them by asking the user or running small experiments.

OPAL

Representation

The Open Platform for Automated Laboratories: human-readable for validation, machine-executable for automation.

TROVE

Translation

A second agent converts OPAL into a node’s own language, beginning with Emerald’s Symbolic Lab Language.

Execution

The node runs it

Robotic handling, instrument runs, and provenance capture inside a 100,000 sq ft facility in Austin.

Closed loop

Results feed back

Outcomes return to TROVE, which adjusts parameters, updates constraints, and proposes improved variants.
